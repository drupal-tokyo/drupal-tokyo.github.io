## AIで作った自作ツールを自慢しよう

* 会議後の振り返りをサポートするツール EchoPad  
  * [https://www.bulblub.com/2024/05/echopad-v0.1/](https://www.bulblub.com/2024/05/echopad-v0.1/)  
  * 2年前に作って今も使っている  
* バイブコーディング、音声入力でキーボードすら打たなくても仕事ができる  
* レシートをOpenStreetMap へマッピングするツール  
  * [https://www.docswell.com/s/tom-konda/59V72Y-mug-jp\_4-receipt-mapping](https://www.docswell.com/s/tom-konda/59V72Y-mug-jp_4-receipt-mapping)  
  * [https://github.com/tom-konda/receipt-mapping-helper](https://github.com/tom-konda/receipt-mapping-helper)  
* 日本酒を飲んだ記録をつけたい。 
  * 当初はNotionで管理していたが5MB以上の画像はアップロードできてないので記録ができない  
  * 専用サイトを作ってみた  
    * 個人の日本酒のビンの画像からSNS用画像やデータを自動で入力できる  
    * Cloudflare R2 とCloudflare Workers でコストを抑えている  
    * 画像もアップロード画像から本物に近い画像を生成している  
* MacOS用キャプチャツール  
  * Skitchが便利だったので、それ風のツール  
  * 随時チャットで4時間くらいで作成  
* Drupalのセキュリティ通知が最近増えている  
  * バイブコーディングで調査レポートをClaud Skillを作成  
  * 報告用テキストまで作成  
  * Cloud Code の Creator Skill   
  * RSS情報 を入れると作れるが、自動化したい。  
    * Hermes Agent だと自動化できるかもしれない
      * [https://hermes-agent.org/ja/](https://hermes-agent.org/ja/)  
    * Open Clew や Microsoft Scout などもある
